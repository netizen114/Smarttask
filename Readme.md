# SmartTask

Aplicación de consola desarrollada en Java para la gestión de tareas personales y laborales.

## Funcionalidades

* Crear tareas personales.
* Crear tareas laborales.
* Asignar prioridades de 1 a 5.
* Definir jornada diurna o vespertina para tareas laborales.
* Listar tareas activas.
* Listar tareas completadas.
* Marcar tareas como completadas.
* Eliminar tareas.
* Validación de entradas del usuario.

## Estructura

El proyecto utiliza programación orientada a objetos mediante:

* Herencia entre `Tarea`, `TareaPersonal` y `TareaTrabajo`.
* Encapsulamiento.
* Polimorfismo.
* Separación de responsabilidades entre `MenuConsola` y `GestorTareas`.

## Ejecución

Ejecutar la clase `Main` para iniciar la aplicación mediante consola.
